# Roadmap

## P0 — Validate vertical slice on Godot hardware
- Open in Godot 4.3+ and eliminate parser/runtime errors.
- Play a full 10-minute run on desktop.
- Export to iOS test device and profile frame pacing with 300–450 enemies.
- Tune boss HP and late-run enemy density from actual play.

## P1 — Production feel
- Integrate first licensed Star Splitter track and metadata.
- Add actual stem/intensity transitions.
- Add screen shake, hit-stop, impact particles, damage numbers, controller support.
- Add pause overlay and explicit resume/quit controls.
- Add safe-area handling and richer accessibility options.

## P2 — Content expansion
- Give Ghost Driver Unit a truly distinct momentum trait.
- Add Minor Collapse and Warm Circuits Rise characters.
- Add second environment and enemy family.
- Add 6–10 more weapons and cross-project evolutions.
- Add meta-progression purchase tree and jukebox.

## P3 — Mobile production
- Pool enemies/projectiles/pickups.
- Benchmark collision loops; migrate hot paths to spatial partitioning if required.
- Configure iOS/Android export presets, icons, launch screen, signing workflow.
- Device QA and battery/thermal profiling.
