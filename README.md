# Star Splitter Forces

An original survivor-style action roguelite built around the Star Splitter Records universe.

## Current playable slice

The Godot 4 project currently includes a complete 10-minute run loop with procedural vector visuals, desktop and touch movement, six weapon families, passive upgrades, randomized level choices, multiple enemy archetypes, elites, a final boss, persistent unlocks, settings, results, and a beat-aware music architecture ready for Star Splitter masters/stems.

### Play

1. Install Godot 4.3+.
2. Open `project.godot`.
3. Run the project.
4. Use WASD/arrows on desktop, or drag on the left side of a touch screen.

The initial character is **Pulse Width Codex**. Winning a run unlocks **Ghost Driver Unit**.

## Music assets

No third-party music is embedded. Add licensed Star Splitter masters/stems under `audio/` and connect them through `AudioDirector`. See `audio/README.md`.
