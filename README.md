# Star Splitter Forces

An exploration-driven action roguelite set in the Star Splitter universe: fly
Rex Fleet explorers through the broken frontier of the Black Drift Reach, tune
in signals from Star Splitter Records projects, and turn each project's
musical language — its **Force** — into how you fight.

Godot 4.3 · GDScript · mobile-first (iOS primary, Android secondary), desktop for development.

## Run it

1. Install Godot 4.3 (standard build).
2. Open `project.godot` and press Play — or `godot --path .` from a shell.

Controls: drag on the left of the screen (or WASD / arrows / left stick) to fly.
Weapons fire automatically. Space / gamepad A = character ability, M = map,
Esc = pause, 1–4 = choose upgrade, R = reroll, E = confront The Silence at the gate.

## Test it

```
tools/run_tests.sh                  # 20 headless gameplay tests (fails on any script error)
godot --headless res://tools/BalanceSim.tscn -- ella_venn pulse_width_codex 7 explore
xvfb-run -a godot --rendering-driver opengl3 res://tools/Capture.tscn -- /tmp/captures
python3 tools/generate_audio.py     # regenerate placeholder score + SFX (numpy + ffmpeg)
```

## Music

No Star Splitter recordings are bundled. The in-game score is original
placeholder audio generated by `tools/generate_audio.py`. Authorised masters
dropped into `audio/catalog/` become playable in the Archive (see `AUDIO_DESIGN.md`).
